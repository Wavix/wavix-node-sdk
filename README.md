# Wavix TypeScript SDK

The official TypeScript SDK for the [Wavix API](https://wavix.com).

> Generated by [Fern](https://buildwithfern.com) from the Wavix OpenAPI
> specification. Generated files are overwritten on each regeneration — keep
> any hand-written files behind `.fernignore`.

## Installation

```sh
npm install @wavix/sdk
```
